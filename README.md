TrainRiser is a smart train ticket booking portal designed to enhance the traditional railway reservation experience. The platform enables users to search trains, compare schedules, select coaches, and proceed through a structured booking flow. Its standout innovation is interactive seat selection, allowing users to visually choose seats based on availability, creating transparency and confidence before payment. Seamless data flow across pages ensures accurate ticket summaries and error-free booking. With a modern UI and intuitive user journey, TrainRiser demonstrates how real-world transport systems can be improved using thoughtful design and efficient frontend logic.

---  How to run ---
1. Download or clone the project folder to your system.

2. Open the project in VS Code or any code editor.

3. Start a local server (recommended) using Live Server.

4. The homepage opens where users enter source, destination, and travel date.

5. Click Search Trains to view available trains and schedules.

6. Select a train and choose a preferred coach (SL, 3A, 2A, or 1A).

7. Click Seat Availability & Book to move to the seat selection page.

8. Visually select available seats using the interactive seat layout.

9. Proceed to the Payment Page, where booking details are auto-filled.

10. Complete the payment to finalize the booking process.
